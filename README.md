# 人生决策助手

一款纯前端的多准则决策分析工具，帮助用户把重要选择拆成选项、维度、权重与依据；它呈现可检验的信息，不替用户做决定。

## 功能

- 新建、编辑、回看和删除本机决策
- 2–6 个候选选项、可编辑维度与权重归一化
- 1–10 分矩阵打分与备注
- 加权排名、总分条形图、维度雷达图、优劣势分析
- 可调权重的敏感性分析、理性建议及冷静期提示
- 一键复制 Markdown 结果

所有数据只保存在浏览器的 `localStorage`；清除站点数据会清除记录。

## 本地启动

需要 Node.js 20+ 与 pnpm：

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
